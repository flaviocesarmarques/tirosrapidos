# Tiros Rápidos

FPS simples em primeira pessoa que roda direto no navegador. Elimine todos os bots da rodada; a cada rodada chegam mais.

Um único arquivo (`index.html`), com HTML, CSS e JavaScript puro desenhando em Canvas 2D por raycasting. Não há dependências nem etapa de build.

## Como jogar

Abra o `index.html` em um navegador de computador e clique em **JOGAR**.

| Ação | Tecla |
| --- | --- |
| Mover | W A S D |
| Mirar | Mouse ou ← → |
| Atirar | Clique ou Espaço |
| Recarregar | R |
| Ligar ou desligar o som | M |
| Pausar | Esc |

## Regras

- O pente tem 30 tiros e a recarga é ilimitada.
- A rodada 1 começa com 5 bots; cada rodada seguinte traz 2 a mais, um pouco mais rápidos.
- Vencer uma rodada recupera 30 de vida.
- O recorde de abates fica salvo apenas no navegador em que você jogou.

## Limitações

Feito para teclado e mouse. Não há controles de toque para celular.
